# tm_76 — 長榮中學高二 化學 第二章 段考題型補充題庫（壓力與壓力計）

- **科目**：化學（高二上）
- **母教材**：tm_28
- **題數**：10 題（單選 8、多選 2），`questionSource` 全部為 `AI_GENERATED`
- **用途**：第一次段考化學有 11 題考壓力與壓力計，其中多題使用非水銀液體（血液、密度 0.8、1.04 g/mL 的液體）。本題庫補上液柱換算與開口式／閉口式的判斷。

## 產出與驗算（誠實揭露）

1. 題目全部由 Claude 依母教材範圍與段考題型原創，不是課本原題，也不是段考原題（段考原題在「月考資料」頁）。
2. 計算題的答案先手算，再由 `source/build-supplements.py` 逐題數值驗算；選項互不重複、答案必在選項中。
3. 多選題選項自帶 (A)～(E) 代號，模擬月考不會打亂其選項順序；全部選對才得分。
