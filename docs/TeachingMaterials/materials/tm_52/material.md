# tm_52 — 補充題庫：tm_10 課本原題（長榮中學高二物理課本 第1章 測量與不確定度）

- **原教材**：`tm_10`（長榮中學，高二物理課本，第1章 測量與不確定度）
- **題數**：14 題（課本範例與例子 5 題；想一想與習題 9 題）
- **原始檔案**：課本掃描在 Project Owner 的 J: 槽「高二第一次月考/物理/測量與.pdf」（課本第1～55頁，24 個跨頁）；本 Package 的 `source/課本原題轉錄.md` 為逐題轉錄稿。

## 為什麼是一份補充題庫

原教材只有 AI 出題，沒有課本本身的題目。依「已上傳的資料不得修改」，課本原題另存為補充題庫，平台產生資料時併入原教材；測驗中心的「原始試卷」出課本原題，「補充練習」出 AI 題，不會混在一起。

## 產出過程（誠實揭露）

1. 掃描的文字層是錯亂的 OCR，無法使用。Claude 把每個跨頁轉正、切成單頁，逐頁看圖轉錄。依賴附圖的題目在題幹開頭標明「依原課本附圖以文字描述」。
2. **課本範例印有解答**：答案照錄，Claude 另行獨立驗算，全部一致。
3. **想一想與習題沒有解答**：答案由 Claude 獨立計算，詳解開頭註明。幾題原為開放式提問的「想一想」改寫成選擇題或是非題，詳解中註明。
4. 每題都有 `reference`（出處：課本第幾頁的範例／想一想／習題）。
