## 本 Package 的產出過程（誠實揭露）

1. 掃描檔的文字層是品質不佳的 OCR，無法直接使用。Claude 把每一跨頁轉成圖片、轉正並切成單頁，**逐頁看圖轉錄**題幹、選項與講義重點。
2. **每一題都由 Claude 獨立重新解題**，再與簡答篇的答案比對，不直接抄簡答篇。140 題全部與簡答篇一致。過程中發現並更正的是 Claude 自己的轉錄錯誤，不是講義的錯誤：
   - 2-2練習8：初稿把「氮氣」誤讀成「氦氣」，以簡答篇 (C) 25 mL 反查後更正（N₂ 為雙原子分子）。
   - 2-3練習3：題目是「氫氣」（H₂）不是「氦氣」，以簡答篇 (D) 1：12 驗算後確認。
   - 2-2非選2：初稿的汞柱方程式列錯，重新列式後得 h ＝ 38 cm、P ＝ 114 cmHg，與簡答篇相同。
   - 大考風向非選1(3) 與素養題：Claude 初次抄錄簡答篇時誤記為 2.84×10⁻³ 克、122 克，重新放大簡答篇第175頁確認為 **2.84×10⁻² 克**、**1122 克**，與獨立計算結果一致。
3. **依賴附圖的題目**：以文字在題幹中描述作答所需的圖形資訊（壓力計汞面高低、容器體積與壓力、函數圖形狀、粒子示意圖的粒子數等），題幹開頭標明「依原講義附圖以文字描述」。圖形選項（例如 2-3練習5、2-3單選13、大考風向單選10）改寫成文字選項，保留原選項代號。
