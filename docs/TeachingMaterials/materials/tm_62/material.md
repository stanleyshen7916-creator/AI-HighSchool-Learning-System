# tm_62 — 長榮中學高二國文 第一～三課 單選／多選補充練習

- **科目**：國文（高二上）
- **範圍**：第一課〈勞山道士〉、第二課〈發明為需求之母〉、第三課〈近體詩選〉
- **題數**：60 題（單選 55、多選 5），全部為 AI 自編
- **用途**：模擬月考只收單選與多選題；既有三課教材（舊版教材庫）共 48 題，本教材補上不重複的題目，使國文月考題庫超過 100 題（2026-10-09 Project Owner：「可接受單選，多選，不要是非題」）。

## 依據與限制（誠實揭露）

1. 原始檔：J: 槽「高二第一次月考/國文/《大崩壞》、《昨日世界》」資料夾的 19 張課本照片（同名 PDF 內容相同）。資料夾名稱取自第二課旁欄的書名，內容其實是第一～三課。
2. 第一課：字詞題逐條依課本注釋（p.9–17）；作者、題解題依 p.6–7。
3. 第二課：作者頁與旁欄「人類大歷史三部曲」（p.22–23）；論點題依既有教材已覆核的課文重點。
4. 第三課：照片部分頁面角度歪斜、字小，詩句採通行原文（與課本一致的名篇）；體裁、押韻、用典等題目。
5. **待確認**：課本 p.16 照片為「頭觸硬壁，驀然而踣」（注釋57：驀然而踣，猛然跌倒；驀，音ㄇㄛˋ），與既有第一課教材所稱「原文為蹶然而踣」不同。本教材不出這一題，留待 Project Owner 確認。
