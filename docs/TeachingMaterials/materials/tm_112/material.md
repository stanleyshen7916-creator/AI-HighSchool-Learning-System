# 歷史 神話、宗教與理性曙光 Final

## ①核心概念

- 神話是人類企圖探索自然和生命意義的成果，可作為研究文明起源的重要題材。
- 兩河流域與埃及因地理環境不同，發展出不同的思維模式：前者對生命悲觀，後者對生命樂觀。
- 希臘神話中每位神明各有職責、個性鮮明，成為文學藝術的最佳題材，也是希臘文化發展的基石。
- 荷馬史詩（伊里亞德與奧德賽）描寫特洛伊戰爭，展現人性的弱點與命運的無常，也呈現人類對自由與美好的堅持。
- 希臘哲學始於泰利斯：他主張「萬物的起源是水」，是人類第一次以事實經驗為思考基礎，被譽為「哲學之父」。
- 蘇格拉底以詰問法引導思考並強調「了解自己」，柏拉圖提出永恆的觀念世界，亞里斯多德重視經驗觀察並建構完整的知識體系，是希臘文化的集大成者。
- 希臘化時代有斯多噶學派（幸福來自德行）與伊比鳩魯學派（現世幸福應受到關注），兩派尋求心靈平靜的方法不同，但都追求個人幸福。
- 羅馬共和初期由貴族掌權、平民受壓迫，經抗爭設置護民官；西元前450年整編的十二表法是羅馬最早的成文法，被視為歐洲法律的淵源。
- 基督教源於猶太教的「一神信仰」，但不同於猶太教視猶太人為上帝唯一「選民」，耶穌主張「神愛世人」。
- 耶穌復活的福音傳開後堅定了追隨者的信仰；使徒保羅與彼得開始向猶太人以外的地區傳教，使基督教成為不分族群的普世宗教。
- 基督徒拒絕崇拜皇帝，被羅馬當局視為背棄傳統而遭迫害約兩百年（教難時期），但信徒不減反增。
- 313年君士坦丁頒布米蘭詔令，基督教取得合法地位；四世紀末狄奧多西一世將基督教立為國教。
- 教宗制度相傳源自耶穌將天國鑰匙交給彼得，羅馬主教因而取得首席權。
- 隱修運動約於四世紀初興起，出現修道院制度；奧古斯丁的神學理論奠定以教宗為首的「教權至上」理論。
- 中古西歐的莊園制度下，農民人身自由受限制但獲得安全保障；查理曼帝國分裂後，語言分化成德語、法語等民族語言。
- 十一世紀爆發「俗人授職衝突」，之後主教選舉須在皇帝或其代表面前舉行；東正教傳至俄羅斯，1453年拜占庭覆亡後俄羅斯統治者自稱「沙皇」。
- 文藝復興的時代特色是重視個人意識、肯定人的自主能力，人們從「重視永生」轉為「現世關懷」。
- 義大利本身是古典文化的發源地，拜占庭帝國滅亡後傳承古典文化的學者紛紛來此避居，成為文藝復興的發源地。
- 方言文學興起：但丁以義大利方言完成《神曲》，薄伽丘《十日談》以1348年黑死病肆虐的佛羅倫斯為背景。
- 馬基維利《君王論》主張英明君主應專注於戰爭、戰法和戰備，反映現實政治的觀點。
- 馬丁·路德發表《九十五條論綱》批評贖罪券，主張「因信稱義」，挑戰教宗權威，開啟宗教改革。
- 喀爾文認為得救與否是上帝預先選定的，與路德的不同處在於不認為僅依靠信仰就能得救。
- 新教勢力擴展後，天主教也多次舉辦內部改革的大公會議，捍衛傳統信仰與維持教會權威。
- 宗教改革促進個人主義的發展；路德教派肯定經商的價值、喀爾文教派主張勤勉簡樸，有利資本主義發展。

## ②章節摘要

**第1章第1節 眾神國度與人的世界**

本節從神話談起：神話是人類探索自然與生命意義的成果，也是歐洲文化藝術的重要題材；兩河流域與埃及因地理環境不同，形成不同的生命態度。希臘人在神話之外發展出哲學，從泰利斯以事實經驗思考世界，到蘇格拉底的詰問法、柏拉圖的觀念世界，再到集大成的亞里斯多德；希臘化時代則有斯多噶與伊比鳩魯兩個學派探討幸福。羅馬方面，平民經抗爭設置護民官，並整編出最早的成文法十二表法。

**第1章第2節 基督教的發展與傳布**

基督教源於猶太教的一神信仰，但主張「神愛世人」；耶穌復活的福音傳開後，經保羅與彼得向外邦人傳教，成為普世宗教。羅馬帝國曾迫害基督徒約兩百年，313年君士坦丁頒布米蘭詔令使其合法，四世紀末更立為國教。中古西歐，隱修運動與修道院制度興起，奧古斯丁的神學奠定教權至上的理論，莊園制度下農民雖受限制卻有安全保障；查理曼帝國分裂後語言分化，十一世紀爆發俗人授職衝突；東方基督教傳至俄羅斯，1453年後俄羅斯統治者自稱沙皇。

**第1章第3節 理性曙光的再現**

文藝復興的時代特色是重視個人意識，人們從「重視永生」轉為「現世關懷」；義大利是古典文化的發源地，拜占庭滅亡後學者來此避居，加上商業發展，成為運動的發源地。文學方面有但丁的《神曲》與薄伽丘的《十日談》，政治思想方面有馬基維利的《君王論》。馬丁·路德以《九十五條論綱》批評贖罪券，主張因信稱義，開啟宗教改革；喀爾文主張得救由上帝預先選定；天主教則以大公會議進行內部改革。宗教改革促進了個人主義，也肯定經商的價值，有利資本主義發展。

## ③重點詞彙

- **神話**：人類原始社會口語相傳、承載族群記憶的故事，逐漸累積成豐富的文化資產。
- **希臘神話**：每位神明各有職責、個性鮮明，是歐洲文學藝術的重要題材。
- **荷馬史詩**：約西元前八世紀完成，包含伊里亞德與奧德賽兩部史詩。
- **泰利斯**：米利都學者，主張「萬物的起源是水」，被譽為「哲學之父」。
- **詰問法**：蘇格拉底以提問引導對方反思、釐清定義的方法。
- **觀念世界**：柏拉圖認為在物質世界之外永恆存在的世界，物質世界只是它的影像。
- **斯多噶學派**：創始人為芝諾，主張幸福來自德行，重視「克制私欲」。
- **伊比鳩魯學派**：認為宇宙由原子組成，人死後如原子散去不再存在，因此現世幸福應受到關注。
- **護民官**：羅馬平民經多次抗爭後設置的職位，用以確保平民權益，是「製衡」的第一步。
- **十二表法**：西元前450年整編的羅馬最早成文法，被視為歐洲法律的淵源。
- **猶太教**：以「一神信仰」為核心，視猶太人為上帝唯一「選民」，其信仰衍生出後來的基督教並影響伊斯蘭教義。
- **十誡**：上帝耶和華透過摩西頒布的十條規定，第一條為不可拜耶和華以外的神。
- **彌賽亞**：猶太人深信上帝會派遣的救世主；基督徒稱耶穌為救世主「耶穌基督」。
- **教難時期**：羅馬當局因基督徒拒絕崇拜皇帝而迫害基督徒長達約兩百年。
- **米蘭詔令**：313年君士坦丁頒布，基督教正式取得合法地位。
- **教宗制度**：相傳源自耶穌將天國鑰匙交給彼得，羅馬主教因而取得首席權。
- **修道院制度**：教士為逃避世俗的誘惑，至山林深處隱居集體修行所形成的制度（隱修運動）。
- **莊園**：中古西歐土地歸莊園主所有、由農民耕作；農民人身自由受限制，但獲得安全保障。
- **俗人授職衝突**：十一世紀世俗君主與教宗之間爆發的政教衝突。
- **沙皇**：1453年拜占庭帝國覆亡後，俄羅斯統治者以拜占庭文化繼承者自居所用的稱號，取意為「凱撒」。
- **七藝**：一個「自由人」所該學習的基本學科（文法、修辭、辯證、算術、幾何學、音樂、天文學），是中世紀大學的主要科目。
- **經院哲學**：以阿奎那為代表，結合亞里斯多德哲學與基督教神學的學說。
- **活版印刷術**：由古騰堡發明的印刷技術，使知識的傳播更為廣泛。
- **個人主義**：重視個人意識、肯定人的自主能力，是文藝復興的時代特色。
- **但丁**：以義大利方言完成長篇史詩《神曲》，奠定方言文學的基礎。
- **十日談**：薄伽丘的著作，以1348年黑死病肆虐的佛羅倫斯為背景，因直接描述人類情欲而遭教會攻擊。
- **贖罪券**：教宗赦免罪罰的憑證；馬丁·路德批評它只是增加貪婪和利己之心。
- **因信稱義**：馬丁·路德的主張，認為信仰即可得救。
- **預選說**：喀爾文的主張，認為得救與否是上帝預先選定的。
- **西發里亞和約**：三十年戰爭後簽訂，使國家主權平等的概念逐漸成形，國際法得到發展。
