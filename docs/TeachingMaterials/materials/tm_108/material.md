## 固定解題流程

- **單一氣體**：列已知與所求 → 統一單位 → 溫度轉 K → 選公式 → 代入 → 寫單位 → 回代驗算。
- **混合氣體**：求各氣體 n → 會反應先扣除 → 加總 → 求總體積與共同狀態 → 總壓 → 分壓。
- **排水集氣**：判斷水面高低 → 水柱除以 13.6 → 修正總壓 → 查水蒸氣壓 → 扣除。
- **圖形題**：先看座標軸和單位 → 圈出固定量 → 判斷正比、反比或水平線。

## 進考場前默寫
