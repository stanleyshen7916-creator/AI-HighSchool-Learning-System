## ① 核心概念

### 1. 氣體性質與狀態變數（2-1）
- 氣體沒有固定形狀與固定體積，會充滿容器。
- 描述一定量氣體狀態的主要變數為壓力 P、體積 V、溫度 T、莫耳數 n。
- 氣體壓力源自氣體粒子碰撞容器壁。
- 氣體定律中的溫度須使用絕對溫度：`T(K) = t(°C) + 273`。

### 2. 氣體定律（2-2）
- **波以耳定律**：定量、定溫時，壓力與體積成反比，`P₁V₁ = P₂V₂`。
- **查理定律**：定量、定壓時，體積與絕對溫度成正比，`V₁/T₁ = V₂/T₂`。
- **定容壓溫關係**：定量、定容時，壓力與絕對溫度成正比，`P₁/T₁ = P₂/T₂`。
- 圖形題先辨認座標軸及固定條件，再判斷正比、反比或等溫曲線。

### 3. 理想氣體方程式（2-3）
- 🔑 `PV = nRT`，連結壓力、體積、莫耳數與絕對溫度。
- `n = W/M`，其中 W 為質量、M 為莫耳質量。
- 代入可得分子量關係式：`M = WRT/(PV)`。
- 由密度 `d = W/V` 可得：`PM = dRT`。
- 使用 `R = 0.082 L·atm·mol⁻¹·K⁻¹` 時，壓力用 atm、體積用 L、溫度用 K。
- 氣體反應題須先配平反應式，再以係數比換算莫耳數。

### 4. 氣體方程式的應用
- 連通容器混合：先依各容器的 P、V、T 求各氣體莫耳數，再求總莫耳數及平衡後狀態。
- 不可直接把不同容器的初始壓力相加；須考慮容器體積及溫度條件。
- 圖表題先讀座標、狀態點與固定量，再選用氣體定律。

### 5. 氣體分壓（2-4）
- **道耳頓分壓定律**：定溫、定容且混合氣體不發生化學反應時，總壓等於各成分氣體分壓總和。
- 🔑 `Pₜ = P₁ + P₂ + … + Pᵢ`。
- **莫耳分率**：`Xᵢ = nᵢ/nₜ`，各成分莫耳分率總和為 1。
- 🔑 **分壓公式**：`Pᵢ = PₜXᵢ`。
- 同溫同體積下，分壓比、莫耳數比及莫耳分率比相同。
- 混合氣體平均分子量可用莫耳分率加權：`M̄ = Σ(XᵢMᵢ)`。
- 若混合時發生化學反應，須先處理反應，再計算剩餘氣體的分壓。

### 6. 水上集氣與水蒸氣壓校正
- 水上集氣所得氣體含有水蒸氣。
- 液面等高時：`P乾燥氣體 = P總壓 − P水蒸氣`。
- 液面不等高時，先依液柱高度修正總壓，再扣除該溫度下水的飽和蒸氣壓。
- 水蒸氣壓隨溫度改變，查表必須使用題目指定溫度。

## 錯題本

### E01｜溫度單位錯誤
- 題型與形式：⭐ 氣體定律計算題。
- 主要考點：查理定律、定容壓溫關係、理想氣體方程式。
- 易錯點與陷阱：將攝氏溫度直接代入比例式。
- 答題策略：先換算 `T(K)=t(°C)+273`，再代入。
- 驗算：確認所有溫度均為 K，且沒有混用 °C、K。

### E02｜R 與單位不配套
- 題型與形式：⭐ 使用 `PV=nRT` 求 n、W、M 或 V。
- 主要考點：理想氣體方程式及單位換算。
- 易錯點與陷阱：使用 `R=0.082`，卻將壓力留在 mmHg 或體積留在 mL。
- 答題策略：使用 `R=0.082 L·atm·mol⁻¹·K⁻¹` 時，統一 atm、L、mol、K。
- 驗算：將結果代回 `PV=nRT`，檢查單位及數值。

### E03｜分子量／密度公式選錯
- 題型與形式：⭐ 給定質量、體積、壓力、溫度求分子量或密度。
- 主要考點：`M=WRT/(PV)`、`PM=dRT`。
- 易錯點與陷阱：混淆總質量 W 與密度 d。
- 答題策略：先辨認題目給的是 W 或 d，再選公式。
- 驗算：分子量單位為 g/mol；密度單位依題目體積單位表示。

### E04｜氣體反應體積比誤用
- 題型與形式：⭐ 氣體反應、生成物或剩餘氣體計算。
- 主要考點：反應式係數與莫耳數比。
- 易錯點與陷阱：反應式未配平；把質量比直接當體積比。
- 答題策略：配平 → 換算 mol → 依係數比計算 → 依狀態求體積。
- 驗算：反應前後各元素原子數守恆。

### E05｜連通容器混合
- 題型與形式：⭐ 不同容器裝不同氣體，開閥後求總壓或分壓。
- 主要考點：莫耳數守恆、總體積及理想氣體方程式。
- 易錯點與陷阱：直接相加初始壓力；忽略容器體積或溫度。
- 答題策略：逐一求 `nᵢ=PᵢVᵢ/(RTᵢ)`，再求總莫耳數及混合後狀態。
- 驗算：確認總莫耳數守恆，並確認計入的容器體積正確。

### E06｜莫耳分率與分壓混淆
- 題型與形式：⭐ 混合氣體求莫耳分率、分壓或分壓比。
- 主要考點：`Xᵢ=nᵢ/nₜ`、`Pᵢ=PₜXᵢ`。
- 易錯點與陷阱：把莫耳分率當質量分率。
- 答題策略：先求各成分 mol，再求總 mol、莫耳分率，最後求分壓。
- 驗算：`ΣXᵢ=1` 且 `ΣPᵢ=Pₜ`。

### E07｜水上集氣校正
- 題型與形式：⭐ 水上集氣、液面高度差及乾燥氣體壓力。
- 主要考點：總壓、液柱壓差、水蒸氣壓。
- 易錯點與陷阱：把集氣總壓當成乾燥氣體壓力；液面高低修正方向錯；漏扣水蒸氣壓。
- 答題策略：先依液面高低修正總壓，再扣除該溫度下水蒸氣壓。
- 驗算：所有壓力單位一致，乾燥氣體壓力應小於含水蒸氣的總壓（液面等高情況）。

### E08｜圖表與固定條件判讀
- 題型與形式：⭐ P-V、V-T、P-T 圖形及多選題。
- 主要考點：氣體定律與狀態變化。
- 易錯點與陷阱：沒看清座標軸；混淆等溫、等壓、等容。
- 答題策略：先圈出固定量，再辨識軸與單位，最後判斷正比／反比。
- 驗算：每一段過程的固定條件均與所選公式相符。

## 二、最容易失分的 6 件事
1. ⚠️ **攝氏不能直接代公式**：先轉 K，`T=t+273`。
2. ⚠️ **R 與單位要配套**：`R=0.082` 時，P 用 atm、V 用 L。
3. ⚠️ **反應題先配平**：係數比是莫耳數比，不是質量比。
4. ⚠️ **混合氣體先算莫耳數**：不能直接把不同容器初始壓力相加。
5. ⚠️ **分壓不是質量分率**：先求 `Xᵢ=nᵢ/nₜ`，再算 `Pᵢ=PₜXᵢ`。
6. ⚠️ **水上集氣要扣水蒸氣壓**：液面不等高時，先做液柱壓力修正。

## 三、解題固定流程
### 單一氣體
已知／求 → 統一單位 → 溫度轉 K → 選公式 → 代入 → 寫單位 → 回代驗算。

### 混合氣體／連通容器
各氣體求 `nᵢ` → 加總 `nₜ` → 求總體積與共同狀態 → 求 `Pₜ` → 求各 `Pᵢ`。

### 水上集氣
判斷液面高低 → 修正集氣總壓 → 查該溫度水蒸氣壓 → 扣除 → 得乾燥氣體壓力。

## 四、圖形題秒判
- P-V：定溫時反比，呈曲線。
- V-T：定壓時與 K 溫度正比。
- P-T：定容時與 K 溫度正比。
