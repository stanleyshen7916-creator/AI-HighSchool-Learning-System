# 歷史 近代歐美面貌的形塑 Final

## ①核心概念

- 科學革命肇始於天文學：1543年哥白尼佐證太陽為宇宙中心的論點，克卜勒以數學公式提出地球繞日軌道為橢圓形，伽利略運用新式望遠鏡直接證實太陽中心說。
- 托勒密的地球中心說與基督教「人在宇宙中心」的概念相通，教會將地心說奉為信條，哥白尼的太陽中心說因與教會理念相左而不敢在生前出書。
- 十七世紀開啟新的研究方法：培根提出歸納法，主張知識的來源是經驗；笛卡兒提出演繹法，主張任何假設都須秉持懷疑精神，並提出「我思故我在」。
- 牛頓是科學革命的集大成者，提出萬有引力定律與三大運動定律，主張宇宙如同巨型機械，依循一定法則運轉。
- 新的研究方法證明人類理性的力量，進一步擴充到人文社會層次，開啟啟蒙運動；康德形容啟蒙是「使人類走出不成熟的狀態」，知識應建構在理性之上，而非盲從權威。
- 洛克是啟蒙運動的先驅，主張天賦人權，認為政府無法保障基本人權時，人民有推翻政府的權力，成為美國獨立革命的主要理論基礎。
- 啟蒙時代的核心思想：盧梭的社會契約論、孟德斯鳩的三權分立與相互制衡、伏爾泰的寬容精神、亞當·斯密的自由放任，以及狄德羅等人合編的《百科全書》。
- 啟蒙運動的影響包括肯定理性與自然法則、抱持進步與樂觀的態度，並奠定現代民主政治的根基；法國大革命正式落實了啟蒙思想。
- 「民主」源自古希臘文，由「人民」與「治理」兩字合成，即人民治理自身事務；古希臘羅馬的民主只有少數人才能享有，不同於現代的民主概念。
- 近代民主制度的思想淵源，絕大部分源自十七至十八世紀歐洲的科學革命、啟蒙運動與工業革命；新興中產階級爭取政治權利，推動了英國國會制度的演進、美國獨立運動與法國大革命。
- 英國：1628年國會與查理一世衝突，引發清教徒革命；1688年光榮革命後，威廉三世簽署權利法案，英國走向君主立憲；1714年喬治一世繼位後逐漸形成責任內閣制。
- 美國：英國因徵稅引發波士頓茶葉黨事件，1776年發表獨立宣言，1781年擊敗英軍；1787年制憲會議制定以牽制與平衡設計三權分立的聯邦共和體制，1789年施行。
- 美國的南北戰爭（1861-1865）由林肯所帶領的北方陣營獲勝，確保了美國的完整性，並促使其工業化與資本主義發展。
- 法國大革命：1789年爆發後，第三階級組成的國民議會頒布《人權與公民權宣言》；1792年國民公會成立第一共和；雅各賓黨實施恐怖統治，之後拿破崙建立執政府（1799）與第一帝國（1804）。
- 1814-1815年維也納會議確立保守主義立場，波旁王室復辟；1830年七月革命、1848年二月革命後進入第二共和，1870年普法戰爭後建立第三共和。
- 法國大革命與拿破崙戰爭廣布民主理念，也刺激民族主義傳播：義大利於1861年建立王國，德意志於1871年建立帝國。
- 工業革命十八世紀後半葉首先出現在英國：大量勞動力、充沛資金、無關稅羈絆的流通管道、廣大的市場，以及煤鐵資源，是開展的要素。
- 光榮革命後國會權力取代王權，由土地貴族與地主掌控的國會推行圈地法案，農民失去土地而成為工業發展所需的勞動力。
- 英國藉海外貿易累積商業資本，發達的銀行業與金融業促進資金流通；皇家學會帶動科學研究，政府頒發專利證書保障發明人，動力機械提高生產效率。
- 工業化成果自十九世紀起由英國向外擴展，先到西歐，再到中歐及東歐，歐陸以外則是美國與日本。
- 工業革命的影響包括都市化普及、中產階級崛起、貧富不均與勞資矛盾，以及大眾文化的出現（咖啡館、音樂廳、歌劇院、博物館為市民提供休閒去處）。
- 資本主義強調保護私有財產、經濟活動自由與市場競爭；工業革命促使資本主義加速發展，形成「工業資本主義」，產業合併也產生大量失業人口。
- 社會主義主張廢除私有財產制、將生產工具改為社會共有，主要學派有烏托邦社會主義、馬克思社會主義與費邊社會主義。
- 新興的中產及勞工階級共同推動「憲章運動」，國會先後通過1832、1867、1884年的改革法案，並在1918至1928年將參政權擴大至女性。

## ②章節摘要

**第2章第1節 理性與自由的力量**

科學革命肇始於天文學，哥白尼、克卜勒、伽利略先後支持並證實太陽中心說，培根的歸納法與笛卡兒的演繹法則建立了新的研究方法，牛頓集其大成。新方法證明人類理性的力量，並擴及人文社會領域，開啟啟蒙運動。洛克以天賦人權為先驅，盧梭、孟德斯鳩、伏爾泰、亞當·斯密與狄德羅等人分別提出社會契約、三權分立、寬容與自由經濟等主張。啟蒙運動肯定理性、帶來進步與樂觀的態度，奠定現代民主政治的根基，法國大革命則將其理念付諸實現。

**第2章第2節 民主的內涵與建構**

民主源自古希臘文，意指人民治理自身事務；近代民主制度的思想淵源多來自十七至十八世紀的科學革命、啟蒙運動與工業革命，新興中產階級則是重要推手。英國經清教徒革命、光榮革命與責任內閣制的形成，走向君主立憲；美國經獨立戰爭與制憲，建立以三權分立為架構的聯邦共和體制；法國大革命推翻君主專制，歷經第一共和、拿破崙帝國與王朝復辟，最終在第三共和落實民主體制。大革命與拿破崙戰爭也刺激民族主義，促成義大利與德意志的統一。

**第2章第3節 工業革命的發展與影響**

工業革命於十八世紀後半葉在英國發生，勞動力、資金、市場與煤鐵資源是主要條件，圈地法案、海外貿易、金融業、專利制度與動力機械則是背景與助力。工業化成果隨後擴展至歐陸與美、日，帶來都市化、中產階級崛起、貧富不均與勞資矛盾，也讓大眾文化出現。工業革命促使資本主義加速發展，並催生社會主義；英國的中產與勞工階級推動憲章運動，透過國會改革逐步獲得選舉權。

## ③重點詞彙

- **哥白尼**：1543年佐證太陽為宇宙中心的論點，其太陽中心說與教會理念相左。
- **伽利略**：運用新式望遠鏡，直接證實太陽中心說。
- **歸納法**：培根提出，主張知識的來源是經驗，須經觀察與實驗得到事實，再歸納出結論、建立通則。
- **演繹法**：笛卡兒提出，主張任何假設都須秉持懷疑精神，未經理性驗證的知識不能信以為真。
- **牛頓**：科學革命的集大成者，提出萬有引力定律與三大運動定律。
- **啟蒙運動**：康德形容為「使人類走出不成熟的狀態」，指人類走出基督教神學與傳統知識權威的狀態。
- **洛克**：啟蒙運動的先驅，1690年發表《政府論兩篇》，提出「天賦人權」。
- **社會契約論**：盧梭提出的《民約論》，認為契約是人民彼此間的約定，個人接受後將主權交付給「普遍意志」。
- **三權分立**：孟德斯鳩在《法意》中設計的立法、行政、司法分立又相互制衡的模式，後來實現於美國憲法。
- **百科全書**：狄德羅與伏爾泰、盧梭等人合編，秉持理性精神，批判傳統知識、傳播啟蒙理念。
- **民主**：源自古希臘文，由「人民」與「治理」兩字合成，即人民治理自身事務。
- **清教徒革命**：1642至1649年，英國國會為反制英王查理一世採行君權神授的專制統治而引發的對抗王權的革命。
- **光榮革命**：1688年國會迎回威廉三世與瑪麗，因革命過程未出現流血衝突而得名，英國自此走向君主立憲。
- **責任內閣制**：喬治一世將內閣會議交由多數黨黨魁處理而逐漸形成，成為日後民主國家政府組成及運作的基本模式。
- **獨立宣言**：1776年起草發表，強調人生而平等與天賦人權，政府違反人民權益時人民有權推翻。
- **第三階級**：法國社會中的農民、工匠與中產階級，需負擔沉重稅收，且參政權有限。
- **人權與公民權宣言**：法國國民議會頒布，確認天賦人權與主權在民為法國的核心價值。
- **恐怖統治**：雅各賓黨為避免受到保王派與反法同盟制約，以殘酷血腥手段整肅異己。
- **維也納會議**：1814-1815年由梅特涅主導，確立「神聖正統」「回復原況」及「補償」三大原則，象徵保守主義抬頭。
- **德意志邦聯**：維也納會議後德意志各邦組成的松散同盟，以奧地利及普魯士為首。
- **圈地法案**：十七至十八世紀英國國會頒布，將田地、牧場與廢耕地圍成大片土地，釋放的農村勞動人口前往城市工廠。
- **動力機械**：十八世紀英國運用水力蒸汽驅動機器生產，使工廠規模不斷擴大，取代家庭手工生產。
- **皇家學會**：1660年成立於英國，帶動科學研究的風潮。
- **專利證書**：政府頒發給技術發明人，保障其經濟利益，使新技術不斷應用於工業。
- **都市化**：工業興起促成城市增長；一國工業化程度愈深，都市化愈明顯。
- **中產階級**：工業革命壯大的階層，雖擁有財富，卻無法享有適當的社會政治地位，容易成為推動改革的力量。
- **資本主義**：以牟利為目的的生產、分配與交換制度，強調保護私有財產、經濟活動自由與市場競爭。
- **有限責任法**：投資人在公司破產時只需對所擁有的股份負責，適度保障投資人的利益。
- **社會主義**：主張廢除私有財產制、平均共享利潤，將生產工具改為社會共有，追求經濟上的民主、平等及共享。
- **憲章運動**：新興中產及勞工階級共同推動的擴大參政權運動，訴求取消參政財產限制、重劃選區及實施祕密投票。
