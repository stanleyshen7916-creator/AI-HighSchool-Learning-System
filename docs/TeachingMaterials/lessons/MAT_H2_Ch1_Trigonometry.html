1-1 · F1

弧度（弳）的定義

課本 p.2–5依上傳教材
老師說

好，大家先想像手上有一條繩子，長度剛好跟半徑一樣。把它沿著圓周彎上去貼好，繩子兩端跟圓心連起來，夾出來的角就叫 1 弳。所以弳其實只是在問一件事：「這段弧，有幾個半徑那麼長？」就這樣，沒有很難。

θ = sr　　⇔　　s = rθ

空間感拖拖看「彎繩」，紅色那段就會貼上圓周。再把 r 拉大拉小：圓變了，可是 1 弳那個角完全沒變。所以弳只看比例，跟圓多大沒關係。
常見錯誤很多同學以為 1 弳很小，其實它有 57.3° 那麼大！一整圈只塞得下大約 6.28 段半徑，2π 就是這樣來的。

扇形面積

課本 p.6–9依上傳教材
老師說

扇形面積這條公式，老師真的不希望你用背的。你想像切披薩：把扇形切成很多細細的一片，然後一片正放、一片倒放排排看。是不是越排越像長方形？高就是 r，底是弧長的一半。長方形面積是底乘高，公式就出來了。

A = 12r2θ = 12rs

空間感按播放，片數越切越多，拼出來的邊就越直，越像「底 ½s、高 r」的長方形。偷偷跟你說，以後學積分，用的就是這種「切細再加起來」的想法。
常見錯誤θ 直接代角度進去。公式裡的 θ 一定要用弳！題目給 120°，先換成 2π/3 再算。

度與弳的換算

課本 p.2–5依上傳教材
老師說

換算這邊，你只要記一句話就好：半圈 = 180° = π。其他通通用比例去換，不用背一堆數字。下面這個量角器很特別，外圈是度、內圈是弳。你轉轉看，兩種講法其實指的是同一個角。

π 弳 = 180°　　1° = π180 弳 ≈ 0.0175 弳　　1 弳 = 180°π ≈ 57.3°

空間感金色虛線是 1 弳的位置，比 60° 小一點點。π/6、π/4、π/3、π/2 這幾個位置，你把它們想成時鐘上的刻度，會比背數字快很多。
常見錯誤計算機停在 DEG 模式，卻輸入弳度。如果你算 sin(π/6) 跑出 0.0091 而不是 0.5，八成就是模式沒切。

應用：圓錐展開成扇形

課本 1-1依上傳教材老師補充
老師說

大家都戴過生日派對那種尖尖的帽子吧？拿剪刀沿著一條斜邊剪開、攤平，就會得到一個扇形。這種題目只要抓住一句話：帽口那一圈有多長，扇形的弧就有多長。扇形的半徑呢，就是帽子的斜邊，也就是母線 l。

2πR = lθ　⇒　θ = 2πRl　　側面積 = 12l2θ = πRl

空間感你看，金色同時出現在圓錐底和扇形的弧上，因為它們根本是同一條線。把 R 拉到很接近 l，帽子變得很扁，扇形就快變成一整個圓了。
常見錯誤把圓錐的高 h 當成扇形半徑。扇形半徑是斜邊 l 喔！高要另外算：h = √(l² − R²)。

1-2 · F1

正弦函數 y = sin x

課本 p.14–19依上傳教材
老師說

sin x 的圖，很多人是硬背形狀。其實它就只是「單位圓上一個點的高度」。點沿著圓走多長的弧，右邊的 x 就走多遠，然後把高度記下來。繞完一圈，波就畫完一個週期。來，先按播放看一次。

定義域 ℝ　值域 [−1, 1]　週期 2π　振幅 1
對稱軸 x = π2 + nπ　　對稱中心 (nπ, 0)

空間感左邊青綠色的弧，被「拉直」變成右邊 x 軸上的青綠線段，兩段一樣長。這就是為什麼畫函數圖時 x 一定用弳，因為它就是弧長。
常見錯誤以為 sin x 在 x = π 最小。其實點走到最左邊時高度是 0，要到 3π/2（正下方）才是最低的 −1。

小試身手在 0 ≤ x ≤ 2π 中，sin x = 1/2 的解有哪些？（可複選，選好按「檢查」）

1-2 · F2

餘弦函數 y = cos x

課本 1-2依上傳教材
老師說

cos x 不用重新學一次！它跟 sin x 根本是同一條波，只是往左挪了 π/2。你拖拖看下面的滑桿，把 sin x 慢慢往左推，推到 π/2 的時候，它就跟 cos x 疊在一起了。

cos x = sin(x + π2)
對稱軸 x = nπ　　對稱中心 (π2 + nπ, 0)　　其他性質與 sin x 相同

空間感盯著那個最高點：它從 π/2 一路滑到 0。最高點搬家了，對稱軸也跟著搬，所以 cos x 的對稱軸是 x = 0、π、2π…
常見錯誤以為 sin 和 cos 的對稱軸一樣。記一句：cos 的對稱軸、對稱中心，都是 sin 的「左移 π/2」。

1-2 · F3

平移與伸縮：y = a sin(bx − h) + k

課本 p.20–25依上傳教材
老師說

這條式子看起來很嚇人，其實四個字母各管一件事：a 管高矮（振幅）、b 管胖瘦（週期 2π/b）、h 管左右、k 管上下。來，一個一個拉，看它們各自做了什麼。

y = a sin(bx − h) + k　＝　a sin b(x − hb) + k
振幅 a　週期 2πb　右移 hb　上移 k

空間感只動 h 的時候注意看：b 越大，同一個 h 讓圖形移動得越少。因為真正的位移是 h/b，不是 h。
常見錯誤看到 sin(3x − π) 就說「右移 π」。要先把 3 提出來：sin 3(x − π/3)，右移的是 π/3。

小試身手y = 2 sin(3x − π) + 1 的圖形，可以由 y = sin x 怎麼變過來？

週期模型：月球亮面比例

課本 p.30–31 例題 5依上傳教材
老師說

課本這題超生活：每兩天記一次月亮亮的比例，點畫出來一看，欸，像不像一條正弦波？那我們就來「調」一條 sin 曲線去貼這些點。四個滑桿調到剛好貼住，你就自己把模型做出來了。

y = a sin(bx − h) + k　　週期 T = 2 ×（最高點 x − 最低點 x）　　a = 最大 − 最小2　　k = 最大 + 最小2

1-2 · F5

正切函數 y = tan x

課本 p.32–35依上傳教材老師補充
老師說

tan x 在單位圓上也看得到：在 x = 1 的地方立一條直線，叫它「切線」。把角的終邊一路延長，打到切線上的高度，就是 tan x。角越接近 90°，終邊越接近跟切線平行，就打不到了，這就是漸近線的由來。

定義域 {x | x ≠ π2 + nπ}　值域 ℝ　週期 π　對稱於原點

空間感把 x 拉到 1.5 附近，看左邊那條延長線變得多陡。它衝出畫面時，右邊的曲線也剛好衝向漸近線。
常見錯誤以為 tan 的週期跟 sin 一樣是 2π。角轉半圈（加 π），終邊還是同一條直線，打到切線的位置一樣，所以週期是 π。

1-3 · F1

和角與差角公式

課本 p.40–43依上傳教材
老師說

這六條公式很多人硬背，背到考試就搞混。我們用一個長方形把它「看」出來：一根長度 1 的棒子斜斜立著，角度是 α + β。它有多高？就是 sin(α+β)。下面這張圖把那個高度拆成兩段，兩段加起來就是公式。

sin(α ± β) = sinα cosβ ± cosα sinβ　正弦同號
cos(α ± β) = cosα cosβ ∓ sinα sinβ　餘弦異號

空間感右邊那條直的邊：青綠 + 金色 = 棒子的高 sin(α+β)。上面那條橫的邊：藍色 − 紅色 = 棒子的水平距離 cos(α+β)。cos 是「減」，因為紅色那段是往回退的。
常見錯誤以為 sin(α+β) = sin α + sin β。拉滑桿看看，兩邊數字完全不一樣。

小試身手（課本例題 2）設 0 < α < π/2、π/2 < β < π，且 cos α = 5/13、sin β = 4/5。求 sin(α + β)。

正切差角與兩直線夾角

課本 p.44–46 例題 4依上傳教材
老師說

斜率其實就是 tan(傾斜角)。兩條直線的夾角，就是兩個傾斜角相減。所以夾角的 tan，直接套正切差角公式就好。你把兩條線轉轉看，夾角的數字會跟著變。

tan(α − β) = tanα − tanβ1 + tanα tanβ = m1 − m21 + m1m2

空間感兩條直線相交會有兩組對頂角，一個 θ、一個 180° − θ，所以答案通常要寫兩個。試試讓 m₁m₂ = −1，夾角剛好 90°，分母變成 0。
常見錯誤直接拿斜率相減當作夾角。斜率是 tan 值，不是角度，要用差角公式。

二倍角公式

課本 p.47 例題 5依上傳教材老師補充
老師說

倍角公式課本是用「和角公式代 α = β」推出來的，很快。老師再給你看一個圖：從圓最左邊的 A 點拉一條線到圓上的 P，在 A 看到的角是 θ，在圓心看到的角剛好是 2θ。用這個三角形，sin 2θ 和 cos 2θ 都能直接量出來。

sin 2θ = 2 sinθ cosθ
cos 2θ = cos²θ − sin²θ = 2cos²θ − 1 = 1 − 2sin²θ　　tan 2θ = 2tanθ1 − tan²θ

空間感AB 是直徑，所以 ∠APB 一定是直角，AP = 2cos θ。P 的高度 = AP × sin θ = 2 sin θ cos θ，這就是 sin 2θ。
常見錯誤cos 2θ 只記一種寫法。題目只給 sin，就用 1 − 2sin²θ；只給 cos，就用 2cos²θ − 1。

1-3 · F4

半角公式

課本 p.47–50 例題 8依上傳教材老師補充
老師說

半角就是把剛剛那張圖倒過來看：圓心角是 θ，從 A 看過去就變成 θ/2。所以 tan(θ/2) 就是那個三角形的「高 ÷ 底」，高是 sin θ，底是 1 + cos θ。一張圖就搞定，根號都不用開。

sinθ2 = ±√1 − cosθ2　cosθ2 = ±√1 + cosθ2　tanθ2 = sinθ1 + cosθ

空間感把 θ 拉大，A 那邊的角也跟著變大，但永遠只有圓心角的一半。這是圓周角定理，高一學過的。
常見錯誤用 sin、cos 的半角公式時忘了「±」。要先看 θ/2 落在哪個象限，再決定正負號。

小試身手（課本例題 8）滑板坡道給高手的角度是 θ，tan θ = 4/3（θ 是銳角）。給初學者的角度減為一半，坡度 tan(θ/2) 是多少？

1-4 · F1

疊合公式

課本 p.55–58依上傳教材老師補充
老師說

兩條波加在一起，居然還是一條漂亮的正弦波！為什麼？看左邊：a sin x 和 b cos x 可以想成兩根互相垂直的箭頭，一起轉圈。頭尾接起來，合起來的箭頭長度固定是 √(a² + b²)，它的高度就是兩條波相加。按播放，看它轉。

a sinx + b cosx = r sin(x + α)
r = √(a² + b²)　　cosα = ar，sinα = br（點 (a, b) 的方向角）

空間感紅色箭頭的長度 r 永遠不變，只是一直轉，所以合成的波振幅就是 r。α 就是點 (a, b) 的方向角，直接在左圖量。
常見錯誤a 或 b 是負的時候，α 不在第一象限。要看點 (a, b) 落在哪個象限再決定 α。

疊合求區間最大值、最小值

課本 p.59–61 例題 3、4依上傳教材
老師說

化成 r sin(x + α) 之後，全範圍的最大值就是 r、最小值是 −r。但考試最愛限定範圍！這時候要把 x + α 的範圍畫在單位圓上，看那段弧最高爬到哪、最低掉到哪。下面拉兩個滑桿改範圍，紅色弧就是 x + α 能走到的地方。

y = −√3 sinx + cosx = 2 sin(x + 5π6)　　−2 ≤ y ≤ 2（不限範圍時）

空間感只要紅色弧有經過圓的最上面（π/2），最大值就是 2；沒經過的話，最高點會落在弧的某一端。最小值看最下面（3π/2）同理。
常見錯誤不管範圍，直接回答 ±r。一定要先檢查 x + α 的範圍有沒有包含 π/2 和 3π/2。
